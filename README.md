# Flipkart Login Automation using Selenium and PyTest

This is my first GitHub project, showcasing a basic automation script using Selenium and PyTest. The project automates the login functionality on the Flipkart website.

#Author : Omkar Chavan

## Features

- Automates the login process on Flipkart.
- Uses Selenium WebDriver to interact with web elements.
- Implements PyTest for test execution and reporting.
- Easy-to-understand structure for beginners in automation testing.

## Requirements

Before you begin, ensure you have the following installed:

- Python 3.7+
- Google Chrome or  Firefox browser
- Selenium WebDriver
- PyTest
